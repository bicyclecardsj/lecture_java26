# ☕ Java 프로그래밍 기초 및 OOP 실습

이 저장소는 Eclipse IDE 환경에서 진행된 자바(Java) 언어의 기본 문법부터 객체 지향 프로그래밍(OOP) 핵심 개념까지의 학습 내용을 기록하는 공간입니다.

---

## 🛠 개발 환경

* **Language**: Java (JDK 8+)
* **IDE**: Eclipse IDE
* **OS**: Windows

---

## 📅 일차별 학습 내용

| 일차 | 주요 학습 주제 | 핵심 개념 및 실습 내용 |
| :---: | :--- | :--- |
| **1일차** | **자바 기본 문법 & 제어문** | • 변수, 연산자, 조건문(`if`, `switch`) 및 반복문(`for`, `while`) 기초 문법 학습 |
| **2일차** | **메서드 및 배열 활용** | • `getCount`, `getMax`, `getSum` 등 통계/집계 알고리즘 메서드 구현<br>• `swapArray`를 활용한 배열 요소 교환 실습 |
| **3일차** | **클래스와 상속** | • 객체 지향 개념(클래스, 객체, 인스턴스)<br>• 생성자, 필드, 메서드 정의 및 `extends`를 활용한 상속 구조 이해 |
| **4일차** | **추상클래스 & 인터페이스** | • `abstract` 클래스를 활용한 다형성의 기초<br>• `interface` 다중 구현 및 표준 규격 설계 이해 |
